uint16_t bios_rgb565 ( int r,
int g,
int b )

Translates standard RGB values into the color palette / scheme of the screen.

Think of it as a translator, but for the colors: your program tells normal values, it translates it to a language the screen can understand. Essential for all the graphics commands.

Parameters
rRed value.
gGreen value.
bBlue value.
Returns
Color in RGB565 format.
gfx_pixel(0, 0, bios_rgb565(255, 255, 255));

◆ gfx_draw_text()

void gfx_draw_text ( int x,
int y,
uint16_t rgb565 )

Draws text on the screen, starting from a specified X and Y coordinate (top-left origin), with a specified color.

Accepts only rgb565 values, use bios_rgb565(r, g, b) to translate from normal RGB values. Only accepts English; for current state of the project will make everything caps-locked. Accepts a little of special symbols; if it can't draw something, will draw a question mark.

Parameters
xX coordinate (top-left origin).
yY coordinate (top-left origin).
rgb565Text color in RGB565 format.

◆ gfx_draw_text_scaled()

void gfx_draw_text_scaled ( int x,
int y,
uint16_t rgb565,
int scale )

Same as gfx_draw_text(), but this command can scale text up by a whole (integer) amount.

Accepts integer values in the 'scale' argument, from 1 to 5. Text is scaled exactly by that 'scale' times; scale 2 is 2 times larger than scale 1.

Parameters
xX coordinate (top-left origin).
yY coordinate (top-left origin).
rgb565Text color in RGB565 format.
scaleScale factor (1–5).
