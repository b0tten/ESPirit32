# **ESPirit32: Breathe life into your hardware.**

*Code less, create more.*

*Fast. Stable. **Yours**.*

## Overview
- **ESPirit32** is an Operating System that prioritises stability and predictability over extra speed.

## Why choose us?
- Espirit is the platform where the goal is to optimise the workflow, not the overclock of the CPU.
- If you need to write your own screen drivers for your app, it is not an OS, it's just a launcher.
- Elif you need to make a different version of your app for all the variations of chips, it's again just an .elf loader 
- Espirit changes that, **sandboxing** was a security *limitation*, now it's a **feature**.

## Our vision:
- Arduino is easy to learn coding with, but it's slow: it's only used to control basic appliances, 11th LED crashes it.
- ESP32 is faster, and is much wider in use than just lighting up LEDs, but hard to code, even harder to learn coding with.
- Here Espirit comes in, it's a bridge that allows you to focus on the actual coding, not the dark EPS32 stuff.
- You will have an easier learning curve(just like the arduino), but will not have the celling of basic features*.
- Code it, it will **just work**.
